# Astrocade

**Historical route:** website Create → editor Game Preview.
**Public status:** browser procedure, not an unattended public adapter.

## Connection and creation

Follow the [browser procedure](../shared/browser-workflow.md). Open
<https://www.astrocade.com/create> in the verified owner-selected logged-in
profile, start a fresh project, retain defaults and submit the approved prompt.
Capture accepted input, visible generation/clarification and final delivery.
Do not infer an undisclosed model, token count or exact completion time.

## Game handoff and input

The historical artifact was an authenticated editor preview in a visible
`Game Preview` iframe using `about:srcdoc`. Identify the visible frame and its
crop/scale for screenshots and ordinary input; **do not read `srcdoc` or hidden
game state**. Record portrait sizing, viewport, zoom and scale. Click to focus
before bounded keyboard actions. Never treat editor text as gameplay evidence.

This is an observed historical UI shape, not a stable selector promise. If the
frame is missing, ambiguous or transformed differently, stop measurement and
retain the transport issue. Do not invent an unprotected play URL, extract
assets from browser caches, or publish the project without separate permission.
Source-less account-only games may provide authorized public screenshots/action
evidence, with access limits disclosed. Never share login credentials or claim
public replay when the game needs the creator's account. Essential unsupported
claims remain unverified; there is no private evidence lane in v1.
