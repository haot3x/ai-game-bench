# Mopan

**Historical route:** the hosted website's ordinary creation chat, not the private
product API adapter. **Public status:** browser procedure only; no unattended
creation wrapper is shipped here.

## Connection and creation

Follow the [browser procedure](../shared/browser-workflow.md). Open
<https://mopan.ai/> in the verified owner-selected profile, use Create/new project,
and inspect the visible model selector. Record its current default; do not hardcode
Gemini or any historical model into a generic platform adapter.

Enter the approved prompt and click the Send arrow. Confirm an accepted user
message/new workspace and generation state. Capture stages, follow-ups and the
final reply. A build-ready message can precede more work; wait for no active
generation state and an accessible final game.

## Game handoff

Retain the final play URL, exposed build identity and observation time privately.
Use a game-only page/surface for evaluation, excluding chat and billing. A play
URL/build query is not proof that the bytes are frozen. No database access,
private prompt export or reverse-engineered API is required for this UI route.
