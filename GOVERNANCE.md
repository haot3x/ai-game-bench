# Governance

AI Game Bench is initiated and currently maintained by Mopan. The initial
maintainer is [@haot3x](https://github.com/haot3x). Anyone may contribute; only
designated Mopan maintainers accept submissions and merge PRs.

## How decisions work

- Apply the same criteria and evidence requirements to every platform, including
  Mopan. Disclose affiliations and review limitations.
- Merge only after required checks and maintainer review. Initially, the same
  maintainer may submit and merge a PR; this is not independent review.
- Passing CI, accepting evidence and independently reproducing a result are
  different claims. Website publication is a separate curated decision.
- Preserve accepted records; corrections add a new revision.

To question a result or propose a rule change, open an
[issue](https://github.com/mopan-ai/ai-game-bench/issues) or
[Discussion](https://github.com/mopan-ai/ai-game-bench/discussions) with supporting
evidence. Maintainers record decisions publicly in the relevant thread or PR.

New maintainers or governance changes require an explicit PR. This initial
structure is not institutionally independent governance.
