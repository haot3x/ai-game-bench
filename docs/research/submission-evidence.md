# Evidence design: current decision and research

The original proposal explored optional private evidence repositories, informed
by [OpenRSI Discussion #209](https://github.com/OpenRSI-Foundation/OpenRSI-Index/discussions/209).

**Superseded for v1:** use public, task-scoped evidence packages in ordinary PRs.
Do not provision private evidence repositories. Raw captures stay local; public
packages require explicit rights/privacy review before upload.

Current contracts, commands and examples: [submitting](../submissions.md).
Trust boundaries and acceptance: [maintainer review](../reviewing-submissions.md).
Harbor records remain canonical for local runs; this is a publication export,
not a new runner or result database. No additional training consent is inferred.
