# Public foundation state

This is a clean-history extraction, not the full private development repository.
The landing site and historical records remain in a separate private repository.

## Included

- Thin `agb` CLI: doctor, task/capability listing, free Harbor run, native-result
  inspection and localhost Harbor Viewer.
- Public submission CLI: policy listing, unapproved drafts, machine-readable
  schemas, allowlisted preparation, offline validation and tree-wide checks.
  The counter calibration is the runnable task. A separate data-only Tetris
  browser pilot has frozen manual checks; it is not an automatic Harbor task.
- Public-by-default result PRs, contributor/agent instructions, synthetic export
  and rejection tests. Structural validity is not authentic gameplay evidence.
- One immutable local DOM click-counter task, version 0.2.0.
- Real-browser verifier: score visibility, initial state, idle stability,
  repeated clicks, runtime errors and blocked external requests.
- Positive/negative fixtures; missing-browser and replay checks.
- Local-only native jobs with screenshots, action logs, frozen bundles and hashes.
- Contribution rules, GitHub workflow definitions and existing report references.
- Six per-platform reference directories (Codex, Claude Code, Mopan, TapTap Maker,
  Manus, Astrocade), with connection procedures, artifact/cost provenance and
  machine-readable descriptors. `agb platforms <name> [--json]` reads them only.

## Not included / not claimed

- No six-platform unattended creation adapter. The Gemini 4 pilot is accepted
  with limitations; it is not an unattended or independently reproduced run.
- No migration of private browser profiles, production Mopan API integration,
  private prompts, raw jobs, screenshots containing accounts or Git history.
- No independently calibrated subjective judge, representative game leaderboard,
  automatic agent optimizer or model training.
- No automatic report deployment, package publishing or official rerun service.
- Local workflow files do not configure GitHub branch rules, reviewers or secrets.
- No automatic browser recorder, uploader or evidence authenticity certification.
  Agents/operators record events locally; upload uses an ordinary fork/PR.
